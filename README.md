## How to Compile and Run
Shell scripts need no compilation. Requires `bash`.

```bash
cd exercise-01 && bash sum.sh < input.txt
cd ../exercise-02 && bash evenodd.sh < input.txt
cd ../exercise-03 && bash factorial.sh < input.txt
cd ../exercise-04 && bash palindrome.sh < input.txt
cd ../exercise-05 && bash calculator.sh < input.txt
```
You can also run any script without `< input.txt` to type input yourself.
Sample output is in each folder's `output.txt`.
